**Description**
A mini RPG simulator where you take your hero on a journey where they fight a warewolf and perform basic hero activities like become a part of a guild

**How to Compile and Run**
*Requirements*
C++ compile

*If on Windows*
- Must have MinG installed

***Compile***
- bashg++ -std=c++14 -o Homework Homework.cpp
***Run***
*Windows:*
bash.\Homework.exe'

*Mac/Linux:*
bash./Homework'

*Windows:*
bashg++ -std=c++14 -o Homework Homework.cpp && .\Homework.exe

*Mac/Linux:*
bashg++ -std=c++14 -o Homework Homework.cpp && ./Homework
